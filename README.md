# Dislexia-e-Usabilidade-A3

Projeto focado em acessibilidade e design front-end para pessoas com dislexia. A partir disso, criamos a Lexi, um site que busca melhorar a experiência de leitura para pessoas com diferentes dificuldades.

## Objetivo
Criar uma leitura mais amigável para pessoas com diferentes dificuldades, utilizando:
- Tipografias adequadas
- Cores acessíveis
- Layout limpo e organizado

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript ES6
- JSON Local
