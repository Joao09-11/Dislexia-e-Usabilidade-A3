# Dislexia-e-Usabilidade-A3

Projeto focado em acessibilidade e design front-end para pessoas com dislexia. A partir disso, criamos a Lexi, um site que busca melhorar a experiência de leitura para pessoas com diferentes dificuldades.

## Objetivo
Criar uma leitura mais amigável para pessoas com diferentes dificuldades, utilizando:
- Tipografias adequadas
- Cores acessíveis
- Layout limpo e organizado

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript ES6
- JSON Local

## Versões do lexi

- lexi.html

- lexi2.html

## Recursos de acessibilidade
- Alto contraste
- Espaçamento de texto otimizado
- Fonte amigável para leitura

## Entrevista para melhoria

Foram realizadas entrevistas com 8 usuários para avaliar a usabilidade da plataforma Lexi. Os participantes apontaram que o menu lateral ocupava muito espaço e dificultava a navegação. Além disso, os livros não recebiam destaque suficiente e a interface foi considerada pouco moderna. Com base nesse feedback, o menu foi reduzido e substituído por ícones, tornando a navegação mais intuitiva. Os cards dos livros foram ampliados e receberam maior destaque visual. Também foram feitas melhorias na organização das informações e na identidade visual do sistema. Após as alterações, novos testes mostraram maior facilidade de uso e satisfação dos usuários. Os resultados indicaram uma melhora significativa na experiência geral de navegação da plataforma.
